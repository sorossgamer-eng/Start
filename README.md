# Start

Сайты и приложения проекта «Генератор прибыли» и «РемонтПро».

Всё, что лежит в этом репозитории, автоматически публикуется на GitHub Pages:
**https://sorossgamer-eng.github.io/Start/**

> HTML-страницы в корне и папка `tg-app` не перемещаются: по их адресам открывается живой сайт и Telegram Mini App.

## Папки

| Папка | Что внутри |
|---|---|
| `tg-app/` | Telegram Mini App «РемонтПро» (калькулятор ремонта). Описание: `tg-app/CLAUDE.md` |
| `backend/` | Сервер для Mini App и панель подрядчика (Node.js) |
| `vibe-sites/` | Пять готовых шаблонов сайтов: шиномонтаж, маникюр, строители, ремонт квартир, мебель на заказ |
| `docs/` | Документы проекта: ТЗ, исследование, планы, инструкции |
| `archive/` | Старые версии страниц, которые больше не используются |
| `.vscode/` | Настройки редактора VS Code |
